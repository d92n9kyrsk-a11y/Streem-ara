# Arabic Stream Providers

A Nuvio plugin repository focused on Arabic-subtitled sources.

## Install in Nuvio

Repository manifest:
`https://raw.githubusercontent.com/d92n9kyrsk-a11y/Streem-ara/main/manifest.json`

In Nuvio, open **Settings → Content & Discovery → Plugins → Add Repository**, paste the manifest URL, refresh, then enable the provider.

## Providers

- **Krmzy** — Turkish content with Arabic subtitles. Initial scraper implementation; requires in-app testing.

## Notes

- Providers return direct MP4/HLS URLs when the source page exposes them.
- This repository does not host video content.
- Availability and playback depend on third-party site changes and Nuvio runtime support.
